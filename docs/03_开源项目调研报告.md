# 03 开源项目调研报告

> 版本：v0.1 | 日期：2026-08-22 | 状态：待评审
> 调研方式：网络检索 + GitHub 检索（含二次开发候选评估）

## 1. 调研结论（TL;DR）

- **二次开发基础选定：STranslate**（[ZGGSONG/STranslate](https://github.com/ZGGSONG/STranslate)）——WPF/C#、MIT、功能最贴合（划词翻译/截图翻译/离线 PaddleOCR/多翻译源/全局快捷键），仅 Windows 符合目标平台。
- **核心屏幕翻译能力借鉴：Translumo**（[ramjke/Translumo](https://github.com/ramjke/Translumo)）——实时屏幕翻译、多 OCR 引擎评分、悬浮窗与「排除自身窗口」设计，Apache-2.0 可商用。
- **登录/后端能力自研**：上游项目均无登录体系，按需求采用 Supabase Auth 自建。

## 3. 基础项目深析：STranslate

### 3.1 为什么选它

1. **技术栈完全一致**：WPF / C#，可直接在 .NET 8 环境编译、改造、打包。
2. **功能覆盖度高**：截图翻译（框选→OCR→翻译）、划词翻译、离线 OCR（PaddleOCR）、全局快捷键、多翻译源切换，与需求 80% 重合。
3. **许可证友好**：MIT，允许闭源商用二次开发，无 GPL 传染风险。
4. **社区活跃**：4.5k star、76 个 tag、长期维护。

### 3.2 需改造/新增的点

| 类别 | 现状（STranslate） | 本项目需求 | 动作 |
|---|---|---|---|
| 登录体系 | 无 | Supabase Auth 登录后才能用翻译 | **新增** Auth 模块 + 登录 UI |
| 屏幕翻译 | 仅「框选区域截图翻译」 | 全屏扫描 + 翻译前确认弹窗 | **改造**：新增全屏模式与确认弹窗交互 |
| 结果展示 | 翻译窗口/结果卡片 | 置顶半透明悬浮窗（原/译对照） | **改造**：新增 Overlay 悬浮窗 |
| 实时连续翻译 | 无 | V1.1 可选 | 借鉴 Translumo 的区域实时翻译 |
| 多显示器 | 支持 | 要求无偏移 | 验证/强化（参考 pingyi 方案） |
| 服务插件 | 较多 | 精简默认引擎 | **裁剪**：只保留常用翻译源 |

### 3.3 建议复用的代码块

- 全局快捷键注册（Win32 RegisterHotKey 封装）
- 屏幕框选截图层（遮罩 + 选区 + DPI 换算）
- OCR 服务抽象层（IOcrService，PaddleOCR 接入）
- 翻译服务抽象层（ITranslateService，多引擎配置）
- 设置持久化与设置窗口
- 托盘常驻

## 4. 屏幕翻译核心借鉴：Translumo

| 能力 | 借鉴内容 |
|---|---|
| 多 OCR 引擎评分 | 同时跑 Windows OCR / Tesseract / EasyOCR，ML 模型选最优 —— 本项目简化为「PaddleOCR 主 + Windows OCR 备」 |
| 悬浮窗设计 | 置顶、无边框、半透明、可拖动，且支持「排除自身窗口」避免自翻译 |
| 低延迟流水线 | 截图 → 识别 → 翻译 多线程管道 + 文本缓存去重 |
| 区域选择 | Alt+Q 框选区域、~ 开始/停止 —— 本项目确认弹窗后可沿用区域/全屏模式 |
| 许可证 | Apache-2.0，可商用；建议仅借鉴思路不复制代码，避免协议混用 |

## 6. 最终开发方案（2026-08-22 决策）

> 决策背景：上游 STranslate 已全面升级到 net10.0-windows，与本项目 .NET 8 技术栈冲突；经用户确认，采用**自建精简工程**方案。

```
STranslate（MIT，仅作架构参考，保留在 STranslate/ 目录）
   + 自建精简工程：src/BettyTranslate.App（WPF UI）+ src/BettyTranslate.Core（领域服务）
   + 技术栈：.NET 8 / WPF / MVVM（CommunityToolkit.Mvvm）
   + 新增 Auth 模块（Supabase Auth 登录/注册/会话）
   + 新增屏幕翻译全流程（确认弹窗 → 全屏/区域截图 → OCR → 翻译 → 悬浮窗）
   + 借鉴 STranslate 的服务抽象与热键/截图/翻译链路模式
   + 借鉴 Translumo 悬浮窗与区域翻译设计（不复制代码）
   + 借鉴 pingyi 多显示器 DPI 处理经验
   = Betty Translate V1.0（MIT 自有部分）
```
