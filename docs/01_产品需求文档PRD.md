# 01 产品需求文档（PRD）

> 版本：v0.1（草案） | 日期：2026-08-22 | 状态：待评审

## 1. 产品概述

### 1.1 背景与痛点

- 用户经常需要使用全英文界面的软件（设计工具、开发工具、专业软件、海外 App 等），因看不懂界面而无法上手。
- 已有方案（浏览器翻译插件、词典）无法覆盖「软件内非可选中文本」「图片内文字」等场景。
- 截图 → OCR → 翻译 → 阅读 的多步操作链路繁琐，用户需要「一键式」解决方案。

### 1.2 产品定位

一款 Windows 桌面屏幕翻译工具：**登录后，一键扫描屏幕，将外文界面实时翻译为中文**。主打「打开即用、确认后翻译、隐私友好」。

### 1.3 目标用户

| 用户类型 | 需求场景 |
|---|---|
| 普通办公用户 | 使用英文版 Office/设计软件时翻译菜单与提示 |
| 开发者 | 翻译英文 IDE、命令行、技术文档截图 |
| 游戏/视频用户 | 翻译游戏界面、硬字幕（进阶能力） |
| 学生/外语学习者 | 阅读英文软件与资料 |

## 2. 核心用户流程

```
1. 启动 App，进入登录页
2. 输入邮箱 + 密码（或注册新账号）登录
3. 登录成功后进入主界面（托盘驻留）
4. 用户打开任意英文软件
5. 按全局快捷键 F1（可自定义）
6. 弹出确认弹窗：「是否进行屏幕翻译？」
   ├─ 点击「是」→ 全屏扫描 → OCR 识别 → 翻译为中文 → 悬浮窗展示
   └─ 点击「否」→ 取消本次操作
7. 用户可关闭悬浮窗或继续翻译其他区域
```

## 3. 功能需求

### 3.1 用户登录（P0，强制）

| 编号 | 需求 | 说明 |
|---|---|---|
| L1 | 邮箱 + 密码登录 | 使用 Supabase Auth，登录成功获取会话 token |
| L2 | 邮箱 + 密码注册 | 注册后自动登录 |
| L3 | 登录态持久化 | 记住登录状态，重启 App 免登录（token 刷新） |
| L4 | 退出登录 | 清除本地会话 |
| L5 | 未登录限制 | 未登录时翻译功能不可用，仅能停留在登录/注册页 |
| L6 | 密码重置（可选） | Supabase 邮箱验证码重置密码 |

### 3.2 屏幕翻译（P0，核心）

| 编号 | 需求 | 说明 |
|---|---|---|
| S1 | 全局快捷键触发 | 默认 `F1`，可在设置中修改 |
| S2 | 翻译前确认弹窗 | 弹窗文案：「是否进行屏幕翻译？」+「是 / 否」按钮 |
| S3 | 全屏扫描 | 对当前屏幕（含多显示器）进行截图捕获 |
| S4 | OCR 识别 | 从截图中识别出文本块及坐标位置 |
| S5 | 文本翻译 | 将识别出的文本翻译为目标语言（默认中文） |
| S6 | 悬浮窗展示 | 结果以置顶、半透明、可拖动悬浮窗展示（原文/译文对照） |
| S7 | 翻译区域可配置 | 支持「全屏」或「框选区域」两种模式（区域模式为增强） |

### 3.3 增强功能（P1，可后续迭代）

| 编号 | 需求 | 说明 |
|---|---|---|
| E1 | 划词翻译 | 选中文本 + 快捷键 → 翻译弹窗 |
| E2 | 截图翻译 | 框选屏幕区域 → OCR + 翻译，结果卡片展示 |
| E3 | 剪贴板监听翻译 | 复制文本自动翻译（可开关） |
| E4 | 多翻译引擎对比 | 同时展示多引擎结果（参照 pot-desktop） |
| E5 | 截图保存/复制 | 翻译结果一键复制、历史记录（可选，注意隐私） |

### 3.4 设置（P0）

| 编号 | 需求 | 说明 |
|---|---|---|
| C1 | 快捷键设置 | 修改屏幕翻译、划词翻译等快捷键 |
| C2 | 翻译引擎选择 | 源语言/目标语言、在线引擎（百度/腾讯/有道/DeepL/Google/OpenAI） |
| C3 | OCR 引擎选择 | PaddleOCR（默认，离线）/ Windows OCR（快）/ Tesseract |
| C4 | 悬浮窗样式 | 字号、透明度、位置记忆 |
| C5 | 开机自启（可选） | 托盘常驻 |

## 4. 非功能需求

| 类别 | 需求 |
|---|---|
| 性能 | 从按下快捷键到悬浮窗出现 < 3 秒（本地 OCR + 在线翻译） |
| 隐私 | 默认离线 OCR，截图不落盘；翻译请求仅发送识别文本，不发送全图（可配置） |
| 安全 | 登录 token 安全存储（DPAPI / Windows Credential Manager）；请求走 HTTPS |
| 兼容性 | Windows 10 19041+ / Windows 11 x64；支持多显示器、不同 DPI |
| 稳定性 | 长驻托盘不崩溃；OCR 失败有降级提示（如改用 Windows OCR） |
| 许可合规 | 自有代码 MIT；使用第三方库遵守其开源协议 |

## 5. V1.0 范围与优先级

### V1.0 必做（MVP）
- 登录/注册（Supabase Auth）
- 屏幕翻译全流程（快捷键 → 确认弹窗 → 全屏 OCR → 翻译 → 悬浮窗）
- 设置：快捷键、翻译引擎、OCR 引擎、语言
- 托盘常驻、退出登录

### V1.1 增强（后续迭代）
- 划词翻译、截图翻译、区域翻译模式
- 多引擎对比、剪贴板监听
- 历史记录、开机自启

## 6. 验收标准（V1.0）

1. 未登录时无法触发翻译，登录后可正常使用。
2. 按 `F1` 弹出「是否进行屏幕翻译？」确认框；点「是」后在 < 3s 内对全屏英文文本完成中文翻译并显示悬浮窗；点「否」不执行任何扫描。
3. 翻译结果悬浮窗可拖动、可关闭，文本可复制。
4. 断网时 OCR 仍可用（离线引擎），翻译给出明确的网络错误提示。
5. 多显示器 + 150% DPI 下截图区域无偏移。
